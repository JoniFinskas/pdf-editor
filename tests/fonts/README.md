# Fixture font provenance

Inter-Regular.ttf is unmodified from the official rsms/inter v4.1 release:
https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip

Archive SHA256: 9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e.
OFL.txt is the release's LICENSE.txt.

PdfEditorFixture.ttf is a renamed, physically subsetted derivative generated by
scripts/subset-fixture.py using fontTools. It retains only the fixture glyphs and
their composite dependencies. Both fonts are used only in headless fixture tests.
