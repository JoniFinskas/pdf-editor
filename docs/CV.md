# Build a CV

Choose **Build CV** from the home screen or All tools. Enter your details,
fill the sections you need, and create the PDF. A current document stays in its
own tab. Form errors stay in the builder with a specific error. Font or layout failures
reopen the entered draft for correction and retry.
Move sections up or down; **Undo remove** restores the last removed section.
The form stays available in the new tab for revisions; rebuilding
creates another PDF rather than overwriting edits made on the page.

The layout uses one column, selectable embedded text, conventional section
headings, body-level contact details and automatic page breaks. It keeps readable
font sizes instead of shrinking a long CV. Text wraps at spaces; repeated spaces
and tabs are normalized. Section headings must be single lines. Shorten an overlong unbroken link or word if it cannot fit.

Use **Review PDF text** to inspect the actual reading order after editing.
Check your name, contact details, dates, experience and skills. Save a copy, then
check the employer's preview and required file format before submitting.

## What ATS software does

An applicant tracking system can parse a resume into candidate fields. Parsing
and hiring decisions are different steps. Employers can also configure automatic
rejection based on application answers, such as a required qualification.
No PDF layout can guarantee passing every system or employer's filters.

Greenhouse documents parsing problems with image-only resumes, graphics,
columns, complex tables, headers/footers, spaced-out letters and contact details
inside text boxes. Its parser has a 2.5 MB limit; other portals can differ.
Use truthful qualifications and clear job titles. Formatting cannot supply a
missing qualification, and keyword stuffing is not a compatibility fix.

The local review checks selectable text, image presence and file size. It does
not emulate a vendor parser, validate every layout, or calculate a ranking.
